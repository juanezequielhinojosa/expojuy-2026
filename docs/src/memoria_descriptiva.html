Desafío Digital ExpoJuy 2026 — Primera etapa.
Prototipo funcional navegable desarrollado con Astro.

Organizador de referencia: Cámara de Comercio Exterior de Jujuy.
Fecha de presentación: septiembre de 2026.

1. Presentación

Este documento acompaña el prototipo funcional navegable del sitio web propuesto para ExpoJuy 2026, presentado en la primera etapa del Desafío Digital. El prototipo fue desarrollado como un sitio real, estático y navegable en Astro, publicado en un repositorio de GitHub, de modo que pueda recorrerse en el navegador exactamente en la forma en que operaría la edición final.

El contenido incluido (expositores, agenda, noticias y sponsors) es de ejemplo y se reemplaza por la información oficial de la organización cuando esté disponible. Sí se aplica el Kit de Diseño oficial (logotipos y tipografía Ambit).

2. Consignas que se abordan

  • Propuesta de identidad web y diseño visual para ExpoJuy.
  • Las secciones mínimas requeridas: Inicio, Sobre ExpoJuy, Expositores, Agenda, Noticias, Plano/Mapa, Sponsors, Contacto, FAQ y Redes sociales.
  • Diseño responsivo (móvil, tablet y escritorio).
  • Stack libre: se eligió Astro + TypeScript (estático, rápido y de bajo costo).
  • Entrega como prototipo funcional navegable en GitHub + memoria en PDF.

5. Arquitectura técnica

  • Framework: Astro 7 (salida estática) con TypeScript estricto.
  • Fuente de datos: módulos tipados en src/data/ (site, exhibitors, agenda, news, sponsors, faqs) que permiten actualizar contenido sin tocar las páginas.
  • Componentes: Header (menú responsive) y formulario de contacto en React; Footer, Hero, SectionTitle, tarjetas de expositor y noticia en Astro.
  • Interactividad: filtro/buscador de expositores, pestañas de agenda y acordeón FAQ en vanilla JS; menú y formulario con React (sin dependencias adicionales).
  • Tipografía: fuentes oficiales Ambit autoalojadas en /fonts/ vía @font-face (sin Google Fonts ni terceros).
  • Gráficos: iconos e ilustraciones vectoriales SVG propios (sin assets externos ni licencias).
  • SEO: layout base con <title>, meta description y Open Graph por página.
  • Publicación: repositorio Git en GitHub; es desplegable en cualquier hosting estático (GitHub Pages, Netlify, Vercel).

6. Cómo se recorre el prototipo

  1. Clonar el repositorio y ejecutar npm install.
  2. Desarrollo local: npm run dev.
  3. Previsualización de la versión de producción: npm run build y npm run preview.
